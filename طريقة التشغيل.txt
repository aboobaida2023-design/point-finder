مرشد النقطة — الإصدار 2.4
=========================

التطبيق يحتاج رابط https حتى يعمل الـGPS والبوصلة (فتح الملف مباشرة من الجوال لا يكفي).

النشر المجاني على GitHub Pages (مرة واحدة، حوالي ٥ دقائق):
1) أنشئ حساباً مجانياً في github.com (اختر اسم مستخدم بالإنجليزي، مثلاً ahmad-survey).
2) اضغط + أعلى الصفحة ← New repository
   - الاسم: point-finder
   - اختر Public
   - اضغط Create repository
3) في الصفحة التالية اضغط الرابط: uploading an existing file
4) فك ضغط الملف، واسحب الملفات الخمسة إلى الصفحة، ثم اضغط Commit changes.
5) ادخل Settings ← Pages (من القائمة الجانبية)
   - Source: Deploy from a branch
   - Branch: main  و  / (root)  ← Save
6) انتظر دقيقة أو دقيقتين، ثم حدّث الصفحة فيظهر الرابط:
   https://اسم-المستخدم.github.io/point-finder/
7) افتح الرابط في الجوال:
   - آيفون (Safari): زر المشاركة ← إضافة إلى الشاشة الرئيسية
   - أندرويد (Chrome): النقاط الثلاث ← تثبيت التطبيق
8) أول مرة: اسمح بالوصول إلى الموقع، وفي الآيفون اسمح أيضاً بالحركة والاتجاه (للبوصلة).

التحديث لاحقاً: ادخل نفس المستودع ← Add file ← Upload files ← اسحب الملفات الجديدة ← Commit.
يبقى نفس الرابط وتبقى نقاطك المحفوظة، ويصل التحديث للجوال تلقائياً.
عند أي تعديل منك غيّر رقم الإصدار في أول سطر من sw.js (مثلاً pf-v2.3).

بديل مجاني آخر: Cloudflare Pages (pages.cloudflare.com) ← Create ← Upload assets ← اسحب المجلد.

تفعيل القراءة الذكية للصور (اختياري):
1) ادخل console.anthropic.com وأنشئ حساباً واشحن رصيداً بسيطاً.
2) من API Keys اضغط Create Key وانسخ المفتاح.
3) في التطبيق: الأدوات ← القراءة الذكية ← الصق المفتاح ← «اختبار المفتاح».

فتح ملف DXF في أوتوكاد:
- الأدوات ← تصدير DXF ← أرسل الملف لنفسك (واتساب أو بريد) ← افتحه في أوتوكاد.
- إذا لم تظهر النقاط اكتب الأمر: ZOOM ثم E (Extents).
- الطبقات: PF_POINTS النقاط · PF_NUMBERS الأرقام · PF_BOUNDARY الحدود · PF_LENGTHS أطوال الأضلاع
  PF_COORDS الإحداثيات · PF_STAKED مواقع التوقيع الفعلية وخط الانحراف.
